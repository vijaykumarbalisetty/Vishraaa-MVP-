# Vishraa – Machine Learning-Based Fashion Recommendation System

## Overview

Vishraa is a Machine Learning-based Fashion Recommendation System that suggests suitable outfits based on user preferences such as occasion, color, and style. The project demonstrates the complete machine learning workflow, including data preprocessing, feature encoding, model training, evaluation, and deployment through an interactive web interface.

## Features

* Outfit recommendations based on user preferences
* Machine Learning-powered prediction system
* Interactive Streamlit web interface
* Data preprocessing using Pandas
* Model training using Scikit-learn
* Real-time recommendation generation

## Tech Stack

* Python
* Pandas
* Scikit-learn
* Streamlit
* Joblib

## Machine Learning Workflow

1. Collect and prepare fashion recommendation data.
2. Encode categorical features using LabelEncoder.
3. Split the dataset into training and testing sets.
4. Train a Decision Tree Classifier.
5. Evaluate model performance using accuracy metrics.
6. Save the trained model using Joblib.
7. Deploy the model using Streamlit.

## How to Run

### Install Dependencies

pip install pandas scikit-learn streamlit joblib

### Train the Model

python train_model.py

### Run the Application

streamlit run app.py
